# EU Public Tenders & Government Contracts B2B Extractor

Automated B2B lead & public procurement extractor from the official European Union TED v3 database.
- **Ideal for:** IT consultancies, SaaS sales teams, and MCP AI Agents.
- **Pricing:** Pay-Per-Event (`$5 / 1,000 tenders`).
- **Deploy command:** `npx apify-cli login && npx apify-cli push`
